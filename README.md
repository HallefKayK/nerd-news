# 🤖 Nerd News

Bot para Discord desenvolvido em Python para agregação e publicação automática de notícias do mundo nerd.

## 🚀 Funcionalidades atuais

- 📰 Busca automática de notícias via RSS
- 🇧🇷 Tradução automática para português
- 🎨 Embeds personalizados no Discord
- 🖼️ Imagens das notícias
- 🗄️ Banco de dados SQLite
- ⏭️ Sistema de prevenção de notícias duplicadas
- ⏰ Publicação automática
- 🎮 Categoria de Games

## 🛠️ Tecnologias

- Python
- discord.py
- Feedparser
- Deep Translator
- SQLite
- Discord API
